# Dynamic Wireless EV Charging
A smart electric vehicle concept that enables wireless
charging while driving.

## Project Overview
This project focuses on wireless power transfer
technology for electric vehicles.
It aims to reduce the need for frequent charging
stops by transferring electrical energy wirelessly
through a charging system.

## Components Used
- Uno
- Copper wire 
- Dc to Dc converter 
- Bridge rectifier 
- Relay 
- MOSFET


## Working Principle
The system uses wireless power transfer to
transmit electrical energy from a transmitter
to a receiver.
The received energy is used for charging
the vehicle battery.

## Applications

 - Electric Vehicles
 - Smart Transportation
 - Wireless Charging Systems

## Future Improvements
- Improved charging efficiency
- Smart battery monitoring
- Real-time charging status
